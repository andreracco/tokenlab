# TokenLab 90-second walkthrough

## 0:00–0:15 — Start with a real system

Open TokenLab on the Product starting system. Point out that the project is a local draft with no signup, then switch briefly between Product, Editorial, and Expressive to show that each preset changes the same token model.

## 0:15–0:35 — Edit once, see the product change

Select `color.brand.600`, change its light value, and apply it. The Forma preview updates immediately while the TokenLab interface stays unchanged. Use Undo and Redo to demonstrate document history.

## 0:35–0:50 — Inspect impact in both directions

With Inspect enabled, select Forma's Create project button. Show its registered token dependencies, then select `action.primary.background` and use **Used by** to return to the button. Call out the explicit contrast pairs and thresholds.

## 0:50–1:10 — Compare a deliberate change

Save a named snapshot, change a spacing or typography token, and open Compare. Show the baseline and current preview at the same width and mode, plus the exact changed token path. Restore the baseline, then Undo the restoration.

## 1:10–1:25 — Export production artifacts

Open Export and show the CSS, light and dark DTCG JSON, Tailwind CSS, and TokenLab project file. Download the CSS file and note that aliases remain variable references rather than flattened values.

## 1:25–1:30 — Close on reliability

Reload the page to show local persistence. Mention keyboard operation, malformed-import recovery, responsive phone and tablet layouts, and automated contrast checks without presenting them as full accessibility certification.
